Part 1. Optic lobe versus central brain with age (run now)

P1.1 What it tests

Nandakumar et al. measured polyploidy by flow cytometry and sequenced RNA from the same brain regions and ages. In the optic lobe polyploidy rises from about 1% to over 20% by day 21; in the central brain it stays much lower. If polyploid cells change their redox genes, the optic lobe should change with age more than the central brain. The notebook measures exactly that difference (an age-by-region interaction) for each gene programme.

QuestionDoes a programme change with age differently in the optic lobe than in the central brain?
How it worksFor each programme score: score = region + age (log2 of days + 1, because the first time point is day 0) + region x age (+ sex). The region x age term is the difference between the optic lobe's and central brain's age slopes. Screens 2 and 3 compare it with random gene sets and stress controls.
Passes whenFalse discovery rate below 0.05, beats random gene sets (p below 0.05) and every stress control (p below 0.05)
What can fool itAnything else that changes with age in the optic lobe only. The paper reports DNA damage and cell cycle genes rising there with age, so a result is a lead, not proof that polyploid cells cause it.
Built-in positive control. The paper reported the p53 head DNA damage response genes (Ku80, Irbp, Cht8, CG3344, CG4734, Fanci, lok, rad50, Xrp1) rising with age in the optic lobe specifically. The EXPLORE: p53 head DNA damage response set should therefore pass. If it does not, the samples may be mislabelled: check the table from Cell 3.

P1.4 Build the table and label the samples (Cell 3)

The Excel columns are named with the sequencing facility's codes (Sample_72006, Sample_72007, ...), while GEO names the samples like 0dFemaleOL1 (day 0, female, optic lobe, replicate 1). Nothing in the files links the two, so Cell 3 pairs them in order: the first Excel column with the first GEO sample, and so on. Region, age and sex are read from the GEO names. The labels are saved as sample_labels.csv in your Drive folder.

Because the pairing is an assumption, Cell 3 then checks it against the data. Samples from the same region resemble each other much more than samples from different regions, so for each sample it finds the most similar other sample and asks whether that one carries the same region label. If the order is right, this is close to 100%; if the columns were in a different order, it falls to about a third (chance). Below 80%, the cell stops.

def read_table(path):
    opener = gzip.open if path.endswith(".gz") else open
    if re.search(r"\.xlsx?$", path):
        return pd.read_excel(path)
    with opener(path, "rt", errors="replace") as h:
        head = h.read(5000)
    sep = "," if head.count(",") > head.count("\t") else "\t"
    return pd.read_csv(path, sep=sep, comment=None, low_memory=False)


def as_matrix(table):
    """Gene x sample numbers from a table whose first text column holds gene IDs or symbols."""
    text_cols = [c for c in table.columns if not pd.api.types.is_numeric_dtype(table[c])]
    num_cols = [c for c in table.columns if pd.api.types.is_numeric_dtype(table[c])]
    if not text_cols or not num_cols:
        return None
    key = max(text_cols, key=lambda c: table[c].astype(str).str.match(r"^FBgn\d+").mean())
    genes = table[key].astype(str).map(lambda g: id2sym.get(g.split(".")[0], g))
    m = table[num_cols].set_index(genes).groupby(level=0).sum()
    return m.loc[:, [c for c in m.columns if not re.search(r"length|^start|^end|chr", str(c), re.I)]]

Part 1, Cell 6 - Screens: does the optic lobe change differently with age from the central brain?

#@title Cell 6 - Screens: does the optic lobe change differently with age from the central brain?
use = info.region.isin(["OL", "CB"]).to_numpy()
d = info[use].reset_index(drop=True)
age = np.log2(d.age_days.to_numpy() + 1)   # +1 because the first time point is day 0
ol = (d.region == "OL").to_numpy(float)
cols = [np.ones(len(d)), ol, age - age.mean(), (age - age.mean()) * ol]
if d.sex.nunique() > 1:
    cols.append((d.sex == "M").to_numpy(float))
D = np.column_stack(cols)
dof = len(d) - np.linalg.matrix_rank(D)
pinv = np.linalg.pinv(D)
c_var = np.linalg.pinv(D.T @ D)[3, 3]
from scipy import stats


def interaction_t(Y):
    """t statistic for (age slope in optic lobe) minus (age slope in central brain), per column of Y."""
    Y = np.asarray(Y, float)
    Y = Y[:, None] if Y.ndim == 1 else Y
    B = pinv @ Y
    resid = Y - D @ B
    s2 = (resid**2).sum(0) / dof
    return B[3] / np.sqrt(s2 * c_var), B[3]


Z = expressed.loc[:, np.flatnonzero(use)].T
Z = (Z - Z.mean()) / Z.std().replace(0, np.nan)
scores = pd.DataFrame({n: Z[v].mean(axis=1).to_numpy() for n, v in PROGRAMMES.items()})
t, b = interaction_t(scores.to_numpy())
result = pd.DataFrame({"programme": scores.columns, "genes": [len(PROGRAMMES[n]) for n in scores.columns],
                       "interaction": b, "t": t, "p": 2 * stats.t.sf(np.abs(t), dof)})
for fam in ("REDOX", "EXPLORE"):
    m = result.programme.str.startswith(fam)
    p = result.loc[m, "p"].to_numpy(); o = np.argsort(p)
    q = np.minimum(np.minimum.accumulate((p[o] * len(p) / np.arange(1, len(p) + 1))[::-1])[::-1], 1)
    qq = np.empty_like(q); qq[o] = q; result.loc[m, "q_fdr"] = qq

level = expressed.mean(axis=1)
bins = pd.qcut(level.rank(method="first"), 20, labels=False)
avoid = {g for v in PROGRAMMES.values() for g in v}
by_bin = {b_: [g for g in level.index[bins == b_] if g not in avoid] for b_ in range(20)}
for n in [n for n in scores.columns if not n.startswith("CONTROL")]:
    draws = np.column_stack([Z[[rng.choice(by_bin[bins[g]]) for g in PROGRAMMES[n]]].mean(axis=1) for _ in range(N_RANDOM_SETS)])
    null, _ = interaction_t(draws)
    i = result.programme == n; obs = result.loc[i, "t"].iloc[0]
    result.loc[i, "random_low"], result.loc[i, "random_high"] = np.quantile(null, [0.025, 0.975])
    result.loc[i, "p_vs_random"] = (1 + np.sum(np.abs(null) >= abs(obs))) / (len(null) + 1)
    worst, which = 0.0, ""
    for c in [c for c in scores.columns if c.startswith("CONTROL")]:
        tc, _ = interaction_t(scores[n].to_numpy() - scores[c].to_numpy())
        pc = 2 * stats.t.sf(abs(tc[0]), dof) if np.sign(tc[0]) == np.sign(obs) else 1.0
        if pc >= worst:
            worst, which = pc, c.replace("CONTROL: ", "")
    result.loc[i, "p_vs_controls"], result.loc[i, "closest_control"] = worst, which
ok = (result.q_fdr < FDR_MAX) & (result.p_vs_random < RANDOM_P_MAX) & (result.p_vs_controls < CONTROL_P_MAX)
result["verdict"] = np.where(result.programme.str.startswith("CONTROL"), "(control)",
                    np.where(ok, np.where(result.t > 0, "passes: rises more with age in optic lobe",
                                          "passes: falls more with age in optic lobe"),

B.1 What this notebook explores

Single-cell ATAC data record where each cell's DNA is open, as short DNA fragments. One copy of the genome cannot give two fragments that overlap, so cells whose fragments overlap a lot must hold more copies of their genome. This notebook uses that to estimate the ploidy of every cell, then compares polyploid and diploid cells of the same type.

What is known (Nandakumar et al. 2020, eLife)

  • Polyploid cells build up after emergence. Newly emerged adult brains are 98-99% diploid. Polyploid cells appear from day 7 and rise until about day 21; most are 4C.
  • Mostly in the optic lobes. By 3 weeks over 20% of optic-lobe cells can be polyploid, far more than in the central brain. Many neuron types, cortex glia and astrocyte-like glia become polyploid.
  • Geminin and Cdc6 control it. Knocking down Geminin in neurons raised optic-lobe polyploidy; knocking down Cdc6 lowered it. Neurons re-enter DNA replication.
  • Oxidative stress drives it. Paraquat and UV raised polyploidy by day 7, and polyploid cells resisted death, independently of p53.
  • Surface glia are highly polyploid but very few (under 5% of polyploid cells), so they may not form their own cluster.

So the data to use are optic lobes from flies at least 1-3 weeks old. In young or central-brain samples, polyploid cells may be as rare as doublets.

Accessibility is not expression. These data measure how open the DNA around a gene is, not how much RNA it makes. Open chromatin usually goes with active genes, but the link is loose for single genes. RNA from the same cells is not available in this dataset. Treat a result as a lead for RNA or protein measurements.

K = 6
SHIFT = np.uint64(32)


def count_overlaps(codes, starts, ends, n, k=K):
    """Per cell, f_x = number of fragments whose left end is covered by x same-cell fragments."""
    codes, starts, ends = (np.asarray(a, dtype=np.uint64) for a in (codes, starts, ends))
    if codes.size == 0:
        return np.zeros((n, k), dtype=np.int64)
    key = (codes << SHIFT) | starts
    order = np.lexsort((ends, key))
    key, ends, codes = key[order], ends[order], codes[order]
    keep = np.r_[True, (key[1:] != key[:-1]) | (ends[1:] != ends[:-1])]
    key, ends, codes = key[keep], ends[keep], codes[keep]
    end_key = np.sort((codes << SHIFT) | ends)
    depth = np.searchsorted(key, key, side="right") - np.searchsorted(end_key, key, side="right")
    depth = np.clip(depth, 1, k).astype(np.int64)
    return np.bincount(codes.astype(np.int64) * k + depth - 1, minlength=n * k).reshape(n, k)

#@title Cell 6 - Ploidy of every cell, from overlapping fragments
GRID = np.exp(np.linspace(np.log(5e-4), np.log(0.7), 90)); LOG_GRID = np.log(GRID)


def _log_categories(p, kappa, artefact, k):
    t = p - 1; a, b = GRID * kappa, (1 - GRID) * kappa
    out = np.zeros((len(GRID), k))
    for s in range(t + 1):
        out[:, min(s, k - 1)] += np.exp(gammaln(t + 1) - gammaln(s + 1) - gammaln(t - s + 1)
                                        + betaln(s + a, t - s + b) - betaln(a, b))
    out = np.maximum(out + artefact[None, :], 1e-300)
    return np.log(out / out.sum(axis=1, keepdims=True))


def _basis(x, knots):
    return np.column_stack([np.ones_like(x), x] + [np.maximum(x - kn, 0) for kn in knots])


def _e_step(C, n, weights, th, kappa):
    lm = np.zeros((len(C), len(PLOIDIES))); ms = np.zeros_like(lm); vs = np.zeros_like(lm)
    for j, p in enumerate(PLOIDIES):
        lp = _log_categories(p, kappa, th["art"], C.shape[1])
        mean = _basis(np.log(2 * n / p), th["knots"]) @ th["coef"]
        joint = C @ lp.T - 0.5 * ((LOG_GRID[None, :] - mean[:, None]) / th["tau"]) ** 2
        norm = logsumexp(joint, axis=1, keepdims=True); post = np.exp(joint - norm)
        lm[:, j] = norm[:, 0]; ms[:, j] = post @ LOG_GRID; vs[:, j] = post @ LOG_GRID**2 - ms[:, j] ** 2
    lj = lm + np.log(weights)
    return np.exp(lj - logsumexp(lj, axis=1, keepdims=True)), ms, vs


def fit_ploidy(C, kappa=8.0, n_iter=40):
    C = np.asarray(C, float); n = C.sum(axis=1); k = C.shape[1]
    rate = np.maximum((C[:, 1] + 0.5) / (C[:, 0] + 1), 1e-4)
    knots = np.quantile(np.log(n), [0.2, 0.4, 0.6, 0.8])
    th = {"coef": np.linalg.lstsq(_basis(np.log(n), knots), np.log(rate), rcond=None)[0], "knots": knots,
          "tau": 0.5, "art": np.r_[0, 0, np.full(k - 2, 1e-4)]}
    w = np.r_[0.9, np.full(len(PLOIDIES) - 1, 0.1 / (len(PLOIDIES) - 1))]
    for _ in range(n_iter):
        resp, ms, vs = _e_step(C, n, w, th, kappa)
        new_w = np.maximum(resp.mean(0), 1e-5); new_w /= new_w.sum()
        X = np.concatenate([np.log(2 * n / p) for p in PLOIDIES]); Y = ms.T.ravel()
        W = resp.T.ravel(); V = vs.T.ravel(); B = _basis(X, knots); r = np.sqrt(W)
        coef = np.linalg.lstsq(B * r[:, None], Y * r, rcond=None)[0]
        tau = max(float(np.sqrt(np.average((Y - B @ coef) ** 2 + V, weights=W))), 0.05)
        d = resp[:, 0]; art = np.r_[0, 0, np.maximum((d[:, None] * C[:, 2:]).sum(0) / max((d * n).sum(), 1), 1e-7)]
        done = np.max(np.abs(new_w - w)) < 1e-4
        w, th = new_w, {"coef": coef, "knots": knots, "tau": tau, "art": art}
        if done:
            break
    resp, ms, _ = _e_step(C, n, w, th, kappa)
    return resp, (resp * ms).sum(1)

B.8 Step 5: main check, more polyploidy than doublets? (Cell 7)

Two cells captured together look exactly like one cell with twice the DNA. About 0.8% of cells per 1,000 recovered in a run are doublets. Two corrections matter. First, doublets have about twice the fragments, so the fragment filter in Cell 5 keeps them more often than single cells: when most cells are below MIN_FRAGMENTS, the kept cells can be several times richer in doublets than the run as a whole. Cell 7 works this out from each run's own fragment counts. Second, a doublet of two different neurons still lands in a neuron cluster, so doublets are not limited to same-type pairs. Each cell type's polyploid rate, with a 95% interval, is compared with the expected doublet share of the kept cells. Cell types whose interval sits above it have more polyploidy than doublets can explain.

Clusters with mixed markers (for example neuron markers low and glia markers high, in a cluster named "neuron") are often made of neuron-glia doublets. A high polyploid rate there is a warning, not a finding.
